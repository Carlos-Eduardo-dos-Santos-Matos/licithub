LicitHub 🏛️

Plataforma Inteligente de Recomendação de Licitações Públicas

Projeto de Trabalho de Conclusão de Curso (TCC) — MVP.

📌 Sobre o Projeto

O LicitHub é uma plataforma desenvolvida para facilitar a busca e a identificação de oportunidades em licitações públicas, ajudando empresas e empreendedores a encontrar processos compatíveis com seu perfil e suas necessidades.

Por meio das informações cadastradas pelo usuário, o sistema recomenda licitações relevantes e auxilia na comparação de preços e oportunidades, tornando a busca mais simples, organizada e eficiente.

Além disso, o usuário poderá acessar diretamente os sites oficiais do governo responsáveis pelas licitações, consultar os editais e obter mais informações para participar dos processos.

🎯 Objetivo

Simplificar o acesso às licitações públicas por meio de uma plataforma inteligente que personalize as recomendações de acordo com o perfil do usuário, contribuindo para uma tomada de decisão mais informada e para a identificação de oportunidades de negócio.

🚀 Principais Funcionalidades

👤 Cadastro e perfil do usuário: registro de informações sobre a empresa, seus segmentos de atuação, produtos e serviços de interesse.

🤖 Recomendação personalizada: identificação e recomendação de licitações compatíveis com o perfil cadastrado.

💰 Comparação de preços: auxílio na análise dos valores disponíveis nas oportunidades identificadas, facilitando a avaliação de custo-benefício.

🔎 Busca de licitações: consulta e visualização de oportunidades de compras públicas.

🏛️ Acesso aos portais oficiais: links para acessar os sites governamentais, consultar editais e verificar as informações completas de cada processo.

📊 Organização de oportunidades: visualização das licitações encontradas para facilitar o acompanhamento e a gestão dos processos de interesse.

💡 Como Funciona?

Cadastro: o usuário acessa a plataforma e cria seu perfil, informando suas características e áreas de interesse.

Análise do perfil: o sistema utiliza as informações cadastradas para identificar oportunidades relevantes.

Recomendação: a plataforma apresenta licitações compatíveis com o perfil do usuário e auxilia na comparação de preços.

Consulta oficial: o usuário acessa o link disponibilizado para consultar os detalhes da licitação diretamente no portal governamental.

Tomada de decisão: com as informações reunidas, o usuário pode avaliar as oportunidades e decidir quais processos deseja acompanhar.

🏛️ Fonte de Dados e Integração

A plataforma tem como referência o Portal Nacional de Contratações Públicas (PNCP), que centraliza informações sobre contratações públicas no Brasil.

PNCP: https://www.gov.br/pncp/pt-br

Documentação da API do PNCP: https://pncp.gov.br/api/consulta/swagger-ui/index.html

A integração com fontes oficiais permitirá consultar informações sobre licitações e disponibilizar links para os respectivos registros, conforme os dados e recursos disponíveis.

🛠️ Stack Tecnológica Planejada

As tecnologias serão definidas conforme a evolução do projeto e os requisitos estabelecidos.

Banco de Dados: PostgreSQL ou MySQL.

Integração de Dados: API pública do PNCP.

Interface: aplicação web responsiva.

Módulo de Recomendação: lógica de filtragem e classificação de oportunidades com base no perfil do usuário.

Prototipação UX/UI: Figma.
